# Boussole

Boussole est une application personnelle de recherche d'emploi, installée sur l'ordinateur de son unique utilisateur (Windows et Linux). Ce dépôt sert uniquement à présenter le projet : le code de l'application n'y est pas publié.

## Utilisation des données de l'API Offres d'emploi de France Travail

Usage strictement personnel et non commercial : l'application recherche des offres d'emploi pour une seule personne, dans la région de Strasbourg.

Les offres sont consultées et conservées uniquement sur l'ordinateur de l'utilisateur, dans une base de données chiffrée. Elles ne sont ni republiées, ni revendues, ni partagées avec des tiers.

Les requêtes sont peu fréquentes (par défaut, une lecture toutes les 6 heures), espacées d'au moins une seconde, et respectent les limites fixées par France Travail.

Pour chaque offre, l'application indique sa source et conserve le lien vers l'annonce d'origine.

## Confidentialité

Aucun compte en ligne n'est nécessaire. Les données personnelles de l'utilisateur restent sur son ordinateur et ne sont envoyées à aucun service tiers par défaut.
